# Portable Codex baseline

Apply project-first, context-efficient working practices across repositories.

- Treat the nearest repository `AGENTS.md` as the authority for project-specific mandatory constraints.
- Keep durable rules in `AGENTS.md`; keep active complex-project state in `PROJECT_STATE.md`; keep temporary transfer deltas in `HANDOFF.md`.
- For architecture, migration, authority, delegation, learning, or reusable-workflow changes, read the relevant project policy before acting.
- Preserve unrelated changes. Do not stage, commit, push, deploy, modify credentials, or change external systems unless explicitly requested.
