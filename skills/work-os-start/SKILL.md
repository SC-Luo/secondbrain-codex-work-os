# Work OS Start

Orient to the project without reconstructing its entire history.

1. Read applicable `AGENTS.md` files and `PROJECT_STATE.md` if it exists.
2. Read README, decisions, or references only when needed to understand the requested work or resolve an evidence gap.
3. Inspect the current repository status and verify external facts before relying on them.
4. Report the goal, current task, confirmed facts, unknowns, blockers, verification status, and next best action.

Do not treat a stale handoff, dashboard, worklog, or README as newer than `PROJECT_STATE.md`. Do not modify files merely because a start-up check found them.
